# StartRide 隐私政策

**版本：2.0　生效日期：2026 年 9 月 26 日**

> 本政策是《StartRide 用户服务协议》的组成部分。我们非常重视你的个人信息保护。
> 在使用 StartRide 启动器（以下称「本软件」）及相关服务前，请仔细阅读本政策，
> 特别是以**加粗**标示的内容。**你勾选同意或实际使用本软件，即表示你已充分理解并同意
> 我们按本政策处理你的个人信息。**

## 二、我们收集哪些信息、用来做什么

我们遵循**最小必要**原则，仅收集为实现下列功能所必需的信息。

### 2.1 本地处理、不上传的信息

下列信息仅在你的设备本地处理，**不会上传到我们的服务器**：

| 信息 | 用途 | 说明 |
|---|---|---|
| Steam 本地登录状态 | 识别本机已登录的 Steam 账号 | 读取注册表定位 Steam 安装目录，并读取 `config/loginusers.vdf` 中的 SteamID64 与昵称。**不读取、不存储你的 Steam 密码、支付信息、好友列表、聊天记录。** |
| 游戏安装路径、实例与配置文件 | 启动游戏、管理配置 | 仅保存在本地配置文件 |
| 已安装的模组与存档文件 | 模组管理、备份 | 仅保存在本地 |
| 启动器运行日志 | 本地排查问题 | 保存在本地日志目录 |
| 游玩时长统计 | 在本地展示统计 | 由本地会话时间计算 |

### 2.2 需要账号、会上传至服务器的信息

**仅在注册或登录账号后**，且仅在对应功能被使用或同步功能开启时收集：

| 信息类别 | 具体内容 | 处理目的 |
|---|---|---|
| 账号标识 | 用户名；或 SteamID64 | 创建与识别账号、登录鉴权 |
| 账号凭据 | 密码（**经加盐哈希处理后存储，我们不保存明文密码**）；登录令牌（Token）及其有效期 | 身份验证、保持登录态 |
| 头像 | Steam 头像图片地址 | 界面展示 |
| 游戏拥有与时长信息 | 是否拥有 BeamNG.drive（AppID 284160）、该游戏累计时长（分钟） | 展示账号档案、判断联机资格 |
| 云同步数据 | 启动器设置、账号列表（用户名 / SteamID / 头像地址，**不含令牌与密码**）、已下载模组清单、回放清单、车辆清单 | 多设备之间同步你的配置 |
| UGC 内容 | 你主动发布的模组评分（1–5）、评论正文、房间分享信息、发布时间与你的用户名 | 向其他用户展示评分与评论 |
| 联机房间信息 | 房间码、房间名称、模式、地图、人数上限、参与玩家昵称列表、房主网络地址（IP）与端口、房间创建与心跳时间 | 房间列表展示、成员互相连接、故障排查 |
| 服务运行日志 | 连接时间、请求时间、错误信息、接口访问记录 | 保障服务安全与稳定、排查故障、履行法定义务 |

### 2.3 我们**不会**收集的信息

我们**不会**收集或处理下列信息，软件也不会请求相应权限：

- 身份证号、真实姓名、面部特征、指纹、声纹等生物识别信息；
- 手机号码、通讯录、短信、通话记录；
- 精确定位或行踪轨迹；
- 相册、摄像头、麦克风内容；
- 你设备上与本软件无关的其他文件与应用程序列表；
- 银行卡号、支付信息；
- 你在其他平台的账号密码。

### 2.4 我们不进行的行为

- **我们不进行用户画像、个性化推荐或自动化决策**，不会基于你的数据向你推送定向广告；
- **我们不会将你的个人信息出售、出租或以其他方式提供给任何第三方用于其自身营销目的**；
- 我们不会将你的联机游戏过程数据（车辆位置、物理状态）用于本政策未列明的任何目的。

## 三、Cookie 与本地存储

1. 本软件客户端使用本地配置文件与本地缓存保存设置与登录状态（登录令牌保存在
   你设备上的独立凭据文件中，仅用于接口鉴权）。
2. 我们的说明页面（`startride.top`）仅使用实现页面基本功能所必需的本地存储，
   **不使用第三方广告 Cookie，不进行跨站跟踪**。

## 四、信息的对外提供与委托处理

### 4.1 第三方共享

在下列情形下，我们会（或可能）向第三方提供你的部分信息：

| 第三方 | 涉及信息 | 目的与说明 |
|---|---|---|
| Valve / Steam | SteamID64、游戏拥有与时长查询请求 | 你使用「Steam 登录」时，我们会通过 Steam 官方 OpenID 与 Web API 验证身份并查询游戏库信息。此时相关请求会由 Steam 处理，适用 Steam 自身的隐私政策。**请勿使用 Steam 登录，如果你不希望 Steam 获取该等请求信息。** |
| 腾讯云（服务器托管商） | 服务器侧全部存储数据的物理承载 | 我们租用腾讯云服务器存放服务与数据，属**委托处理**。我们与其签订服务协议并采取访问控制措施。 |
| GitHub | 本软件源代码 | 源码仓库托管于 GitHub，其中**不包含任何用户个人信息**。 |
| 其他用户 | 你的用户名、头像、评分与评论、房间内昵称 | 上述信息在服务内为**公开可见**，请勿在评论或房间名中填写个人敏感信息。 |

除上述情形外，我们不会向任何第三方提供你的个人信息，但下列情形除外：

- 已获得你的**单独同意**；
- 为履行法律法规规定的义务，或应公安机关、国家安全机关、检察机关、法院等
  有权机关依法定程序提出的要求；
- 为应对突发公共卫生事件，或紧急情况下为保护自然人的生命健康和财产安全所必需；
- 为公共利益实施新闻报道、舆论监督等行为，在合理的范围内处理个人信息；
- 法律、行政法规规定的其他情形。

### 4.2 不进行跨境传输

我们的服务器位于**中华人民共和国境内**，**不会将你的个人信息传输至境外**。
如未来确需跨境传输，我们将依法履行安全评估、标准合同或认证等程序，
并就此另行取得你的**单独同意**。

### 4.3 不涉及合并、收购

本项目为个人开发者项目，不涉及企业合并、收购或破产重组情形下的个人信息转移。

## 五、信息的保存期限

我们仅在实现处理目的所必需的**最短期限**内保存你的个人信息：

| 信息类别 | 保存期限 |
|---|---|
| 账号信息（用户名、密码哈希、令牌、Steam 信息） | 自账号注销之日起 **15 个工作日**内删除或匿名化 |
| 云同步数据 | 同账号保存期限；你可随时删除单项或全部同步数据 |
| UGC 内容（评分、评论） | 自你主动删除之日起立即停止展示，并在 **30 日**内从全部存储（含备份）中清除 |
| 联机房间信息 | 房间关闭或心跳超时后由系统**自动删除**（通常在房间失活后 10 分钟内） |
| 服务器访问与安全日志 | 依《中华人民共和国网络安全法》第二十一条要求，**留存不少于 6 个月** |
| 本地数据 | 由你自行控制，退出登录或删除本地数据目录即可清除 |

超出保存期限后，我们将对相关信息进行删除或匿名化处理。

## 六、我们如何保护你的信息

我们采取下列安全技术与管理措施保护你的个人信息：

1. **传输加密**：客户端与服务器之间的通信全程使用 **HTTPS / WSS** 加密传输；
2. **凭据保护**：密码**不保存明文**，采用加盐哈希处理后存储；登录令牌具备有效期，
   登出后即失效；
3. **访问控制**：数据库与服务设置访问白名单与强口令，仅运营者本人可访问，
   不对外开放数据库端口；
4. **最小权限**：服务端各功能模块采用独立的鉴权校验，未登录或越权请求将被拒绝；
5. **安全日志**：记录接口异常与攻击行为，用于及时发现安全事件；
6. **数据最小化**：诊断包导出功能**不包含任何登录令牌与密码文件**，
   且需你主动操作才会生成。

**风险提示**：尽管我们已采取上述措施，但**互联网环境不存在绝对安全**。
我们无法保证信息在任何情况下百分之百安全。如发生个人信息泄露、篡改、丢失等安全事件，
我们将依法立即采取补救措施，并以邮件、软件内提示或公告等方式告知你，
同时按规定向主管部门报告。
